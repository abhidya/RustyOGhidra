# Port dossiers

Validated `port_1to1` LLM outputs are saved here. Each file covers one Borg family and one action
index and conforms to `../schemas/port-dossier.schema.json`. Evidence bundles may also be kept here
with the `.bundle.json` suffix.

Do not treat a dossier as ROM authority merely because it is present. Claim-level status and
evidence tiers remain the gate.
